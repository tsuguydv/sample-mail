# smart-letters (static HTML/CSS/JS)

This is a plain HTML/CSS/JS version of the original Next.js project.

## Files
- `index.html` — landing page
- `login.html` — login
- `company.html` — company info (protected)
- `params.html` — email parameters (protected)
- `templates.html` — template selection (protected)
- `result.html` — split editor + full preview + export download (protected)

## Run locally
Open `index.html` in a browser (or use any static server).  
State is stored in `localStorage`.

## Notes
- API is mocked in `assets/api.js` to keep everything in HTML/CSS/JS only.
